# ds-build — сборка экранов из индекса ДС

Вторая половина связки: `ds-ingest` внёс систему в `ds/`, `ds-build` собирает по ней экраны. Главный принцип: агент работает **с индексом, а не со всей Figma**. В контекст берём только нужные части индекса и тянем конкретные компоненты по Node ID в момент вставки.

Скилл самодостаточен, опирается только на артефакты `ds/` текущей среды.

## Главная ценность

- Экраны собираются **композицией реальных компонентов** (инстансы по Node ID), а не рисуются с нуля.
- Цвета/радиусы/типографика — через **семантические токены** из `ds/foundation.md`, поэтому экраны консистентны между собой.
- Контекст не переполняется: читаем карту + нужную категорию деталей, не всю библиотеку.

## Когда вызывать

«Собери экран / макет / страницу из ДС», «добавь экран X», «свёрстай по дизайн-системе». Требует наличие `ds/CONTRACT.md` (если нет — сперва `ds-ingest`).

## Поток (с апрувом перед canvas-write)

1. **Контекст** ([`references/compose.md`](references/compose.md)) — прочитать `ds/CONTRACT.md`, карту `ds/components.md`, токены `ds/foundation.md`. Понять, из чего собираем.
2. **Подбор + план** ([`references/compose.md`](references/compose.md)) — выбрать компоненты под задачу (по назначению/вариантам), подтянуть нужный `ds/components/<категория>.md` за деталями (слоты, Node ID, размеры). Показать **план композиции текстом**: список секций и компонентов с Node ID. **Дождаться апрува.** Markdown бесплатен, перерисовка — нет.
3. **Сборка** ([`references/build.md`](references/build.md)) — `use_figma`: каркас-фрейм (Auto Layout) → инстансы компонентов по Node ID → текст в слоты → привязка цветов к семантике. Инкрементально, по секциям, с проверкой.
4. **Проверка** ([`references/verify.md`](references/verify.md)) — скриншот + аудит: всё привязано к ДС, нет прибитого hex, компоненты реальные инстансы, нет наложений/обрезок.

## Инварианты (из ds/CONTRACT.md)

1. **Компоненты — только из каталога.** Инстансы через `createInstance()` от мастеров по Node ID из `ds/components.md`. Не рисуем контролы с нуля.
2. **Цвета — только семантика** из коллекции `mode` (`background`, `card`, `primary`, `border`, `muted-foreground`, ...). Прибитый hex запрещён.
3. **Радиусы/отступы** — через токены (`radius-*`, шкала). Auto Layout везде, top-секции FILL × HUG.
4. **Иконки точечно** по имени (Lucide и др.), не тянем библиотеку.
5. **План до canvas-write.** Текстовая композиция подтверждается до сборки.
6. **Перед `use_figma` — загрузить figma-use** (skill или `skill://figma/figma-use/SKILL.md`), в вызовах `skillNames:"resource:figma-use"`. Async API, шрифты грузить перед текстом, возвращать ID созданных узлов.

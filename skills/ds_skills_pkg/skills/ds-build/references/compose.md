# Фаза 1-2 — Чтение индекса и план композиции

## Что читаем (и чего НЕ читаем)

Читаем только:
- `ds/CONTRACT.md` — правила.
- `ds/components.md` — карта (что есть, Node ID, в какой категории).
- `ds/components/<категория>.md` — детали нужных компонентов (слоты, варианты, размеры). Тянуть **только нужные категории**, не все.
- `ds/foundation.md` — семантические токены.

НЕ открываем саму Figma-библиотеку и не читаем все детали подряд. В этом смысл индекса.

## Подбор компонентов

По задаче-экрану выбираем компоненты по назначению из карты, сверяем детали:
- Базовое поле формы → `Input/With Label` (`588:108`).
- Цельное поле с хелп-текстом → обёртки `Field/*`.
- Кнопка действия → Button set `73:3681` (вариант `Type=primary`).
- Строка списка/настройки → `Item`.
- Каркас приложения → `Sidebar` (Open) + контент.
- Оверлей → вариант `State=open`.
Учитывать заметки индекса (демо-композиции вставлять как есть; матрица Button в именах вариантов).

## Формат плана (показать до сборки, дождаться апрува)

```
Экран: <название>, размер <WxH или адаптив>
Каркас: Auto Layout <VERTICAL/HORIZONTAL>, фон = surface-токен

Секции (сверху вниз):
1. <Секция> — компонент <Имя> (Node ID `..`, вариант ..) → текст в слоты: <слот=значение>
2. ...

Токены: фон <background>, карточка <card>, кнопка <primary>, обводка <border>, текст <foreground/muted-foreground>
Иконки: <если нужны, имена lucide/*>
```

После апрува — переходить к `build.md`. Без апрува canvas не трогаем.
